# datenoio Homebrew tap

Homebrew formulae for [datenoio](https://github.com/datenoio) tools.

```bash
brew install datenoio/tap/undatum
```

or

```bash
brew tap datenoio/tap
brew install undatum
```

| Formula | Description |
|---------|-------------|
| [`undatum`](Formula/undatum.rb) | Convert, inspect, validate and transform data files ([datenoio/undatum](https://github.com/datenoio/undatum)) |

`Formula/undatum.rb` is rendered from
[`packaging/homebrew/undatum.rb.in`](https://github.com/datenoio/undatum/blob/master/packaging/homebrew/undatum.rb.in)
and updated by the undatum release workflow; change the template there, not the formula here.
